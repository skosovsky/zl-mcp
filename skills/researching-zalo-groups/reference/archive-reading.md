# Чтение сохранённого архива

Проверь наличие `zalo_list_archive_sources`. Если чтение нужного периода из
корпуса не дало данных, а сохранённый источник доступен, используй его;
`stored_message_count=0` не означает пустой архив. Не запрашивай телефонную
синхронизацию для повторного просмотра уже сохранённого источника.

Выбирай `source_id` из discovery, сопоставляя дату capture и период запроса.
При нескольких подходящих копиях и неоднозначном выборе уточни источник.
Даты capture, сохранения и исходного cache expiry различаются; effective retention
`until_owner_deletion` означает хранение до удаления владельцем. Это не обещание
полноты пакета или всей истории аккаунта.

Передай тот же `source_id` в `zalo_list_conversations`, затем в
`zalo_list_conversation_messages` с точным typed ID и явными RFC3339
`since`/`until` для `[since, until)`. Без `source_id` эти tools читают корпус.
Архивный каталог использует исходное сопоставление IDs и текущие локальные
имена: null name и отсутствие совпадения имени не доказывают отсутствие чата.
Количество файлов в источнике не расширяет текущую политику доступа.

Продолжай по `next_cursor` с неизменными источником, датами и порядком.
Пустая страница с `has_more=true` может содержать только неподдерживаемые,
просроченные или отклонённые строки: это не конец периода. Различай
source/period rows и examined-page counters. `history_complete=false`, WAL,
неизвестные авторы, неподдерживаемые данные и ограничения сопоставления
локальных удалений должны оставаться явными в выводах. При
`SOURCE_CONTROLS_UNCLASSIFIED` не объявляй чат пустым: файл нельзя безопасно
прочитать до уточнения семантики его controls.

Ссылайся на источник, тип/ID диалога, `archive_row_id`, время и доступного автора.
`zalo_message_id` может отсутствовать; не выдумывай его из архивной идентичности.
При обрезке читай выданный `resource_uri` через resources/read. Resource содержит
полную проверенную запись; не конструируй URI самостоятельно и не подменяй его
corpus context tool. Архивные записи с `quote_anchor_eligible=false` не могут
служить якорями исходящего ответа, даже при наличии genuine Zalo ID.

Архив читается локально без скачивания, phone sync, импорта, Events и уведомлений.
Новые сообщения относятся к текущему сборщику и корпусу; сохранённая копия сама
не обновляется. Если период выходит за capture, явно укажи эту границу.

`source_information_rows` считает распознанные информационные записи во всём
файле; `unsupported_content.native_information` — пропущенные записи текущей
страницы. Их содержимое не возвращается. Это не сообщения об отзыве и не новые
события; не вычитай полный файловый счётчик из счётчиков выбранного периода.
Пустая страница с такими записями и `has_more=true` требует продолжения.

В новой версии `source_native_excluded_rows` считает все строки, исключённые
штатным потребителем, а `source_information_rows` — их информационное подмножество.
Не складывай эти два полных файловых счётчика. `source_recall_rows` относится
к подтверждённым записям отзыва в снимке; `suppressed_source` — к скрытым строкам
текущей страницы. Это не время отзыва и не новое событие. Скрытый текст не
восстанавливай через другую копию или цитату; пустые страницы продолжай по cursor.
Отсутствующие optional counters у старой версии не означают полноту или ноль
всех служебных записей. Не обходи SOURCE_CONTROLS_UNCLASSIFIED и не инициируй
phone sync вместо разбора уже сохранённого источника.
