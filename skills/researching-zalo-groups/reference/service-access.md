# Доступ к единому сервису

Один постоянный `zl-mcp service` содержит collector, SQLite и MCP. Локальный `serve` предоставляет tools/resources через STDIO-мост к этому сервису; запуск клиента не создаёт ещё один collector. Для исследования достаточно доступных tools; определять транспорт по имени подключения не нужно.

- Если tools отсутствуют, сообщи, что требуется подключение zl-mcp. Не запускай сервис, не меняй config и не читай bearer token в рамках исследования.
- Если MCP отвечает, но collector находится в auth_required, reconnecting или stopped, читай доступный корпус с оговоркой. Auth_required не означает отсутствие сохранённых сообщений и не требует QR для их чтения.
- При ошибке следуй next_action из результата в пределах задачи. Не запускай повторный login или вступление автоматически. Если чтение недоступно, сообщи о конкретном ограничении.
- Resources читай по URI, полученному от сервера, через стандартный resources/read клиента. Отсутствие записи после retention не означает, что сообщения никогда не было.

MCP Events доступны через основной HTTP transport совместимого клиента; наличие tools в STDIO не означает поддержку Events. Получение событий не является необходимым условием исследования по запросу пользователя. Подписки, callback verification, подписи, очередь и повторы обслуживают сервер и клиентская интеграция, а не этот skill.

Отсутствие уведомления не доказывает отсутствие сообщения в корпусе: сначала проверь его через поиск и контекст. Режим сбора all не расширяет существующую групповую подписку. Прочитанное сообщение могло быть сохранено до активации подписки или вне её scope. Если записи нет, connected и пустой replay не доказывают, что история полна: очередь Events не может восстановить запись, которую upstream не отдал.

Наличие zalo_send_direct_message не расширяет исследовательский workflow: он остаётся чтением. Для нового поручения отправки нужны точный получатель и текст/правило пользователя. Фильтры incoming/first_incoming_only доступны в профиле Events v2, но не определяют полноту поискового корпуса. first_incoming=true означает первое локально известное входящее, не первое за всю историю Zalo.
