# Формат результата

Начни с ответа на вопрос пользователя. Затем приведи подтверждения: короткий отрывок, название и ID группы, ID сообщения, автор и время. Если источник не содержит имя автора, укажи его ID и не выдумывай имя.

Пример для синтетического корпуса:

> В группе «Нячанг: быт» обсуждали обслуживание кондиционеров. В сообщении m-101 от 1 октября мастер обещал визит на следующий день; факт выполненной работы этим сообщением не подтверждается.
>
> Источник: «Нячанг: быт», группа g-1, сообщение m-101, автор user-7, 2026-10-01T08:00:00Z: «Мастер обещал приехать завтра».

При необходимости добавь противоречия и открытые вопросы. В конце укажи ограничения: доступный период, известные разрывы, остановленный collector, неполный replay или наличие непросмотренных страниц. Не называй локальный корпус полной историей группы.
