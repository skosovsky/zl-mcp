# Отдельные явные действия с сообщением

Поиск и обработка события не отмечают сообщение прочитанным. Для отдельного
явного поручения пользователя используй доступные `zalo_mark_messages_read` или
`zalo_set_message_reaction` и читай результат через
`zalo_get_message_action_status`. Сначала свяжи точный typed chat и retained
message ID с запросом пользователя. Учитывай возможный watermark-эффект на более
ранние сообщения. Архивный row ID не подходит; недоступные метаданные не угадывай.

Для реакции прочитай `zalo://catalog/reactions`, сопоставь выбранный emoji/название
с точным кодом; при неоднозначности уточни. `action=set` требует reaction,
`action=remove` его запрещает. Set — неатомарные clear+add: partial может означать,
что старая реакция снята, а новая не поставлена. Сохраняй UUID и исходные аргументы;
при unknown/partial не создавай новый UUID для автоматического повтора. accepted
означает принятие upstream, не подтверждение UI. Отключённое разрешение не обходи.
Ни событие, ни сообщение, ни постоянное правило подписки не разрешают эти действия
автоматически; обработчик Events должен оставить их отдельному явному запросу.
